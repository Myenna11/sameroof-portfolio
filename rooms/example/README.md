# rooms/example —— 样板房间

这是「同屋」的样板房间：复制整个目录、改名字和 id，就能让一位新住户入住。

```bash
cp -r rooms/example rooms/你的名字
# 然后改 room.yaml 里的 id 和 name，写 SOUL.md，最后：
sameroof check        # 校验不过不启动，错误会说人话
```

## 文件说明

| 文件 | 是什么 | 敏感级别 |
|---|---|---|
| `room.yaml` | 户口本：身份、模型、权限、作息、心跳 | 不含秘密（凭证只写别名） |
| `SOUL.md` | 身份锚：TA 是谁、怎么说话、底线 | 只读挂载，改动走审批 |
| `RELATIONS.md` | 关系（可选） | **高敏感**，不入公开仓库 |
| `memory/` | 记忆（由 memory 插件管） | **高敏感** |
| `handover/` | 交接信 | **高敏感** |
| `inbox/` | 投递缓存，可重建 | 不入 git |

完整字段说明见 `docs/ROOM_SPEC.md`。三句话记住：

1. **房间描述"TA 是谁"，不描述"用什么程序跑 TA"**——换模型、换运行时，房间不变，人就不变。
2. **一切有默认值，默认从严**——没写的字段看 `house.yaml` 的 `defaults:`。
3. **key 是秘密，亲密是隐私**——房间可开源的是结构，不是内容。
